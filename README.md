# StartupConnect Ethiopia

A team-based web and mobile platform that connects **startups, investors, and mentors** in one digital ecosystem.

## Overview

StartupConnect helps startups discover investors and mentors, manage connections, participate in mentorship activities, and access tools that support collaboration and growth.

## Key Features

- Role-based authentication and authorization
- Startup, investor, mentor, and admin accounts
- Startup and project management
- Investor and mentor discovery
- Connection requests and invitations
- Mentorship scheduling
- Messaging and notifications
- Document and resource management
- Search and filtering
- Dashboards and activity tracking
- English and Amharic support
- AI-assisted recommendations, document summarization, and chatbot features

## Architecture

The project is organized into three main applications:

```text
Startup-Connect-Ethiopia/
├── frontend/     # Web application
├── backend/      # REST API and server-side functionality
├── Mobile/       # Flutter mobile application
└── README.md
```
