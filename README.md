# StartupConnect Ethiopia

StartupConnect Ethiopia is a web and mobile platform designed to connect **startups, investors, and mentors** in one digital ecosystem. The platform helps startups discover relevant opportunities, connect with potential investors and mentors, manage collaboration, and access services that support business growth.

The project was developed as a **team-based final-year Software Engineering project** with web and mobile applications supported by a backend API.

## 🚀 Features

* 🔐 Role-based authentication and authorization
* 👤 Startup, Investor, Mentor, and Admin profiles
* 🏢 Startup profile and project management
* 🤝 Startup–mentor and startup–investor connections
* 📩 Requests, invitations, and collaboration workflows
* 💰 Investment and payment-related workflows
* 📅 Mentorship session scheduling and management
* 💬 Communication and messaging features
* 📄 Document and project-resource management
* ⭐ Ratings and feedback
* 🔎 Search, filtering, and discovery
* 🤖 AI-powered recommendations
* 📝 AI-assisted document summarization
* 💬 AI chatbot functionality
* 📊 User dashboards and activity information
* 🌐 Support for English and Amharic

## 👥 User Roles

### Startup

Startups can:

* Create and manage their profiles
* Present their projects and business information
* Discover investors and mentors
* Send and receive connection requests
* Participate in mentorship activities
* Manage project documents and resources
* Explore personalized recommendations

### Investor

Investors can:

* Create and manage investor profiles
* Discover startups
* Review startup information
* Connect with startups
* Participate in investment-related workflows

### Mentor

Mentors can:

* Create and manage mentor profiles
* Connect with startups
* Offer mentorship services
* Manage mentorship sessions
* Communicate with startups
* Provide feedback and ratings

### Admin

Administrators can:

* Manage users and platform activities
* Review and verify profiles
* Monitor platform interactions
* Manage reported or submitted content
* Support overall platform administration

## 🤖 AI Features

StartupConnect Ethiopia integrates AI-based functionality to improve how users discover and interact with information on the platform.

Key AI features include:

* **Recommendations:** Helps match startups with potentially relevant investors and mentors.
* **Document Summarization:** Helps users obtain concise summaries of uploaded documents.
* **AI Chatbot:** Provides users with an interactive assistant within the platform.

## 🎯 Project Goal

The goal of StartupConnect Ethiopia is to make it easier for startups to find the right **investors, mentors, and collaboration opportunities** while providing a centralized platform for managing these interactions.

The platform aims to support Ethiopia's growing startup ecosystem by bringing key stakeholders together in one accessible digital environment.
